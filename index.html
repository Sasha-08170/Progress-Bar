Прогресс-бар скролла на JavaScript

HTML-структура

Структура прогресс-бара очень простая — всего два вложенных div-элемента:

Внешний контейнер (.progress-container) — это фиксированная полоса вверху экрана. Внутренний элемент (.scroll-content) — это сам индикатор прогресса, ширина которого будет меняться.

CSS-стили прогресс-бара

Контейнер прогресс-бара

Контейнер создает светло-серую полосу вверху экрана, на которой будет отображаться прогресс: 
.progress-container {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 12px;
    background-color: rgba(0, 0, 0, 0.1); 
    z-index: 1000;
  }
  • position: fixed — прикрепляет элемент к окну браузера
  • top: 0; left: 0; — размещает элемент в верхнем левом углу
  • width: 100% — растягивает на всю ширину окна
  • height: 12px — задает высоту полосы
  • background-color: rgba(0, 0, 0, 0.1) — задает фон
  • z-index: 1000 — обеспечивает отображение поверх других элементов

Сам прогресс-бар

Этот элемент будет увеличиваться по мере прокрутки страницы: 
.scroll-content {
    height: 100%;
    width: 0; 
    background: #3498db; 
    transition: width 0.2s ease-out; 
    position: relative;
  }
  • height: 100% — занимает всю высоту контейнера
  • background: #3498db; — цвет
  • width: 0 — изначально ширина 0
  • transition: width 0.2s ease — обеспечивает плавное изменение ширины

JavaScript-логика

Этот код заставляет прогресс-бар работать:

function updateProgressBar() {
    const scrollTop = window.scrollY;
    const docHeight = document.documentElement.scrollHeight - window.innerHeight;
    const scrollPercentage = (scrollTop / docHeight) * 100;
    const scrollContent = document.querySelector('.scroll-content');
    scrollContent.style.width = scrollPercentage + '%';
  }
  
  window.addEventListener('scroll', updateProgressBar);

Подробный разбор

Давайте разберем каждую часть:

  • function updateProgressBar() {...}

    Функция обновляет прогресс-бар при каждом вызове.

  • const scrollTop = window.scrollY;

    Получает текущую позицию прокрутки в пикселях от верха.

  • const docHeight = document.documentElement.scrollHeight - window.innerHeight;

    Вычисляет прокручиваемую высоту страницы.

  • const scrollPercentage = (scrollTop / docHeight) * 100;

    Переводит прокрутку в проценты.

  • const scrollContent = document.querySelector('.scroll-content');

    Находит элемент прогресс-бара.

  • scrollContent.style.width = scrollPercentage + '%';

    Устанавливает ширину в процентах.

  • window.addEventListener('scroll', updateProgressBar);

    Обновляет при прокрутке.

Как это работает вместе?

Процесс такой:

  • Страница загружается — прогресс-бар инициализируется
  • Вы прокручиваете — ширина обновляется
  • Меняете размер окна — ширина пересчитывается
Прогресс-бар виден сразу и плавно реагирует на любые действия!
